About the Pirate Brig model

A fast two-masted pirate brig made for real-time games. Hull, sails, rigging, rails, gun ports, wheel and flag are separate objects, so you can animate the sails, hide the guns or swap the flag without touching the rest of the ship.

The model is built to real-world scale (about 44 m long) and uses PBR materials: wood and metal at 2048, sails and rigging at 1024. It drops straight into Unity, Unreal Engine or Godot as FBX or GLB, and the Blender file has the textures packed in.

Use it as the player ship in a pirate or naval battle game, as a ship in a harbour, or as a hero prop in a cinematic. It shares one art style with the man-o-war, cannon and pirate island from the same set.
